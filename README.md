# zlwx_front

智旅文宣后台前端项目

## 技术栈

- Vue 3 + Vite
- Vue Router 4
- Pinia
- Axios

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 项目结构

```
src/
├── api/          # API 接口封装
├── components/   # 公共组件
├── views/        # 页面组件
├── router/       # 路由配置
├── stores/       # Pinia 状态管理
├── styles/       # 全局样式
└── utils/        # 工具函数
```
