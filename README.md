# zlwx_front

智旅文宣后台前端项目

## 技术栈

- Vue 3 + Vite
- Vue Router 4
- Pinia
- Axios

## 开发

启动开发服务器：

```bash
npm install
npm run dev
```

开发服务器运行在 `http://localhost:3000`，并将 `/api` 请求代理到
`http://127.0.0.1:8080`。

**注意：** 前端依赖后端 API 服务，请先启动 `zlwx_backend` 仓库中的 Python 后端。

当前图文发布流程为：

1. 在“图文发布”页选择小红书并输入讲解词；图片可不传，最多上传 8 张。
2. 前端按需上传图片并创建工作流，轮询后端返回的前 4 条热点。
3. 选择“生成同款”后，生成页按 `runId` 恢复进度并展示真实生成结果。
4. 生成完成且小红书账号预检成功后，可直接点击“一键发布”；质量报告不再阻止发布。

“开始检索”默认使用真实链路：百炼提取具体主题、实体和内容切面并生成 6～8 个多角度检索词，
redbook CLI 读取当前登录会话采集小红书数据，再结合主题相关性、模板价值和真实热度重排 Top 4。
“生成同款”只加载当前选择的模板风格；切换模板时会清理旧风格产物。用户未上传图片时，每个
新工作流默认随机生成 3～6 张不同构图的图片。首次使用或登录状态过期时，请先更新本地小红书
登录状态。详细环境变量、文本模型和图片模型配置见后端仓库 `zlwx_backend` 的 README。

## 构建

```bash
npm run build
```

```
├── router/       # 路由配置
├── stores/       # Pinia 状态管理
├── styles/       # 全局样式
└── utils/        # 工具函数
```
